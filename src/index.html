# About me

I'm a developer who likes turning an idea into something people can open, tap and use. Full-stack web engineering and mobile app creation are the two things I enjoy most, and I move between them comfortably.

On the web, I build high-performance MERN stack applications with clean REST APIs, responsive interfaces and sensible database design. On mobile, I create cross-platform Flutter apps from a single Dart codebase, polished enough to ship.

I care about readable code, fast load times and interfaces that work on every screen size. If you have a product to build, I'd like to hear about it.
